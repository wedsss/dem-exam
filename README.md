# Шаг за шагом — подготовка к ДЭ

## Что добавлено
- Живая подсветка SQL и C# в упражнениях и решениях экзамена, цветные примеры и легенда. Работает офлайн.
- 28 подробных SQL-уроков в 6 модулях, 56 проверяемых упражнений.
- Разбор синтаксиса, результатов, ошибок и перенос навыка на новые предметные области.
- 8 практических заданий официального образца КИМа, оригинальные приложения.
- 3 авторских варианта: мебель, пекарня, типография; контрольные результаты.
- 3 авторские вариативные практики: отмена заказа, склад, отчёт и CSV.
- Таймер 210 минут, сохранение попытки, дневник проверки и экспорт прогресса.
- Разбор завершённой попытки: сравнение чисел с эталоном авторского варианта, 14 практических проверок и замечания к типичным ошибкам в приложенном SQL/C#.
- Для каждого замечания: причина, исправление, повторный тест и ссылка на урок; после исправлений можно обновить и скачать разбор.

Откройте index.html в браузере. Для автономной работы скачайте offline-trainer.zip,
распакуйте полностью и откройте index.html. Внешние зависимости не нужны.

SQL-проверка учебная, по шаблонам. SQL Server и C# в браузере не выполняются.
Полный пробный экзамен выполняется в SSMS и Visual Studio.
Отметки результатов являются самопроверкой, не официальной оценкой.
Анализ кода ограничен отдельными правилами, не заменяет запуск и проверку преподавателем. Код обрабатывается и сохраняется только в браузере; не вставляйте настоящие пароли.
Авторские варианты не являются официальной вариативной частью колледжа.

practice.sql создаёт временные таблицы в SSMS, не изменяя EnterpriseDB.
Для упражнений заменяйте dbo.Books на #Books и аналогично для других таблиц.

Прогресс хранится в браузере. Перед переходом на другое устройство экспортируйте JSON.
Старый прогресс уроков первой версии сохранён отдельно от нового SQL-курса.
